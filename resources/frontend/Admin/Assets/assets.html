Import items from Excel

Copy the table from Excel (with the first row of titles) and paste it here, or choose a .csv file. Every row becomes a non-consumable item, and the IIN numbers are given in the order of the rows. Titles that are understood: Unit Code, Item, Qty, Brand, Model, Make, Color, Size, Serial, Unit Price, Date, Condition, Remarks, Category. The Qty can be like "41 units". The Unit Code is the code of a Section / Unit (for example MRm102).
